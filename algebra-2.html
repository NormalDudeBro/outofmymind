1.5 Graphing Linear Functions and Inequalities

Page 1 · Lines 1–24

1o Linear Tables
2-> Solve for y before building a table.
3-> x + 3y - 6 = 0 gives 3y = -x + 6.
4-> Divide by 3: y = -x/3 + 2.
5-> x values: -6, -3, 0, 3, 6.
6-> y values: 4, 3, 2, 1, 0, respectively.
7-> Plot the ordered pairs; connect with a straight line.
8-> Check: 6x + 2y = 10 gives y = -3x + 5.
9o Intercepts and Slope
10-> For 3x - 2y = -12, set y = 0 to find x.
11-> 3x = -12 gives the x-intercept (-4, 0).
12-> Set x = 0: -2y = -12 gives (0, 6).
13-> Draw the line through these two intercepts.
14-> In y = (3/2)x - 4, slope is 3/2.
15-> Start at (0, -4); move right 2 and up 3.
16-> Slope means change in y divided by change in x.
17o Inequality Boundaries
18-> Replace the inequality sign with = for the boundary.
19-> Use a solid line for <= or >=; equality is included.
20-> Use a dashed line for < or >; equality is excluded.
21-> For y < mx + b, shade below the boundary.
22-> For y > mx + b, shade above the boundary.
23-> Dividing by a negative reverses the inequality sign.
24-> The same reversal applies when multiplying by a negative.

34-> Let x = test grade and y = homework grade.

42-> A system's solution satisfies every inequality.
43-> Keep only the overlap of all allowed regions.
44-> The grade region includes (100, 100), not (0, 0).
45-> Its corners are (600/7, 100), (100, 100), (100, 200/3).
46-> A function assigns exactly one output to each input.
47-> An inequality region generally allows many y values per x.
48-> Do not treat a shaded region as a function graph.

1.6.1 Piecewise Functions

Page 1 · Lines 1–24

1o Choosing a Branch
2-> A piecewise function uses different rules on input intervals.
3-> Choose the branch by the input, not by the output.
4-> First compare x with each branch's interval condition.
5-> Substitute into only the rule whose condition holds.
6-> An included input must have exactly one output.
7-> Check boundary inputs carefully for < versus <=.
8-> An input outside all listed intervals is outside the domain.
9o Worked Piecewise Example
10-> Illustrative example using three distinct input intervals.
11-> Define f(x) = 2x for x < 0.
12-> Define f(x) = 3 for 0 <= x < 2.
13-> Define f(x) = -x + 5 for x >= 2.
14-> f(-2) = 2(-2) = -4 using the first branch.
15-> f(1) = 3 using the middle branch.
16-> f(4) = -4 + 5 = 1 using the last branch.
17o Restricted Graphs
18-> Graph each rule only on its assigned input interval.
19-> For the example, draw y = 2x only to the left of x = 0.
20-> Mark (0, 0) open; mark (0, 3) closed.
21-> Draw y = 3 from x = 0 up to, but not including, x = 2.
22-> The middle branch has an open endpoint at (2, 3).
23-> The last branch includes (2, 3); the final point is closed.
24-> Thus f(0) = 3 and f(2) = 3, each with one output.

25o Jersey Total Cost
26-> Let n be the number of jerseys; C(n) is total cost.
27-> The domain is positive integers, not all real numbers.
28-> C(n) = 88n for 1 <= n <= 5.
29-> C(n) = 75n for 6 <= n <= 11.
30-> C(n) = 65n for 12 <= n <= 29.
31-> C(n) = 56n for n >= 30.
32-> These are all-units discounts: one rate for the whole order.
33o Jersey Calculations
34-> For 11 jerseys, choose the 6 through 11 tier.
35-> C(11) = 75(11) = 825 dollars.
36-> For 25 jerseys, choose the 12 through 29 tier.
37-> C(25) = 65(25) = 1625 dollars, not 1885.
38-> C(5) = 440, while C(6) = 450.
39-> C(11) = 825, while C(12) = 780: total cost can fall.
40-> C(29) = 1885, while C(30) = 1680.
41o Rates and Model Checks
42-> An all-units price changes for every item at a tier boundary.
43-> A progressive rate applies each rate only to its own band.
44-> Do not add earlier tier costs in this all-units model.
45-> Unit price is constant within tiers and jumps between them.
46-> Total cost rises within tiers; it is not a step function.
47-> Plot separate integer points; do not fill gaps in the domain.
48-> Tier prices jump; the integer-domain total has tier changes.

1.6.2 Step Functions

Page 1 · Lines 1–24

1o Step Function Basics
2-> A step function is constant on each input interval.
3-> Its graph consists of horizontal segments or rays.
4-> Output changes at boundaries between steps.
5-> Outputs form a discrete set in the usual step models.
6-> Inputs may vary continuously across real intervals.
7-> A context may instead allow only discrete inputs.
8-> State the domain from the model, not just the picture.
9o Greatest Integer Rule
10-> floor(x) is the greatest integer less than or equal to x.
11-> It rounds down toward negative infinity.
12-> floor(10.7) = 10 because 10 <= 10.7 < 11.
13-> floor(-6.35) = -7 because -7 <= -6.35 < -6.
14-> floor(5) = 5; an integer stays unchanged.
15-> floor(-0.2) = -1, not 0.
16-> Truncation toward zero is not floor for negative nonintegers.
17o Floor Intervals
18-> For an integer k, floor(x) = k when k <= x < k + 1.
19-> The left endpoint is closed; the right endpoint is open.
20-> y = 0 on 0 <= x < 1; y = 1 on 1 <= x < 2.
21-> y = -2 on -2 <= x < -1.
22-> At x = -1, use the next step: floor(-1) = -1.
23-> The domain of floor(x) is all real numbers.
24-> The range of floor(x) is all integers.

1.6.2 Step Functions

Page 2 · Lines 25–48

25o Transformed Floor Rule
26-> Let f(x) = floor(2x - 1); let k be an integer.
27-> f(x) = k exactly when k <= 2x - 1 < k + 1.
28-> Add 1: k + 1 <= 2x < k + 2.
29-> Divide by 2: (k + 1)/2 <= x < (k + 2)/2.
30-> Each step has width 1/2, closed left and open right.
31-> The domain is all real numbers; the range is all integers.
32-> A positive input coefficient preserves endpoint order.
33o Transformed Examples
34-> For k = 0, f(x) = 0 on 1/2 <= x < 1.
35-> f(0.75) = floor(0.5) = 0.
36-> At x = 1, f(1) = floor(1) = 1, not 0.
37-> For k = -1, f(x) = -1 on 0 <= x < 1/2.
38-> f(0.25) = floor(-0.5) = -1.
39-> For k = -2, f(x) = -2 on -1/2 <= x < 0.
40-> f(-0.25) = floor(-1.5) = -2.
41o Context and Endpoints
42-> Parking fees can stay constant within each time bracket.
43-> Read each interval and its included endpoints from the source.
44-> Open circles exclude points; closed circles include them.
45-> Two included outputs at one input violate the function rule.
46-> Included branches with the same output still give one value.
47-> Two open endpoints at an input may leave it out of the domain.
48-> Check boundary values before using a step model for a charge.

1.6.3 Absolute Value Functions

Page 1 · Lines 1–24

1o Absolute Value Rule
2-> Absolute value measures distance from zero, never negative.
3-> |x| = x if x >= 0.
4-> |x| = -x if x < 0.
5-> For example, |-5| = -(-5) = 5 and |5| = 5.
6-> The parent graph is a V with vertex (0, 0).
7-> Its domain is all real numbers; its range is y >= 0.
8-> Opposite inputs have equal absolute values.
9o General Graph Form
10-> Write y = a|x - h| + k, with a != 0.
11-> The vertex is (h, k); the symmetry line is x = h.
12-> The domain is all real numbers.
13-> If a > 0, the V opens upward and the range is y >= k.
14-> If a < 0, the V opens downward and the range is y <= k.
15-> The left branch slope is -a; the right branch slope is a.
16-> Larger |a| makes a steeper V; smaller |a| makes it flatter.
17o Upward Worked Example
18-> For y = |x - 1| + 3, a = 1, h = 1, and k = 3.
19-> The vertex is (1, 3); the symmetry line is x = 1.
20-> The minimum output is 3; the range is y >= 3.
21-> At x = 0 or x = 2, y = 4.
22-> At x = -1 or x = 3, y = 5.
23-> For x < 1, y = -(x - 1) + 3 = -x + 4.
24-> For x >= 1, y = x - 1 + 3 = x + 2.

1.6.3 Absolute Value Functions

Page 2 · Lines 25–48

25o Downward Worked Example
26-> For y = -(2/3)|x + 3| + 1, h = -3, not 3.
27-> The vertex is (-3, 1); the symmetry line is x = -3.
28-> Since a = -2/3, the maximum output is 1.
29-> The domain is all real numbers; the range is y <= 1.
30-> The left slope is 2/3; the right slope is -2/3.
31-> At x = -6 or x = 0, y = -(2/3)(3) + 1 = -1.
32-> Plot these symmetric points and draw the two rays.
33o Equation Strategy
34-> Isolate the absolute value before splitting into cases.
35-> For |u| = q with q < 0, there are no real solutions.
36-> For q = 0, solve u = 0; for nonconstant linear u, one root.
37-> For q > 0, solve u = q or u = -q.
38-> If u is linear with nonzero slope, q > 0 gives two roots.
39-> For nonlinear u, the number of roots can differ.
40-> Check roots in the original equation for extraneous roots.
41o Solve and Check
42-> Solve 2|x - 1| + 3 = 11: first get |x - 1| = 4.
43-> x - 1 = 4 or x - 1 = -4 gives x = 5 or x = -3.
44-> Check both: 2(4) + 3 = 11, so both are solutions.
45-> |x + 2| = -3 has no solutions: distance cannot be negative.
46-> |x + 2| = 0 gives x = -2, exactly one solution.
47-> Squaring |x + 2| = -3 would falsely suggest x = 1 or -5.
48-> Both fail the original equation; reject those extra roots.

1.7.1 Parent Functions

Page 1 · Lines 1–24

1o Parent Functions
2-> A parent is a basic function used to build a family.
3-> R means all real numbers; inf means infinity.
4-> Domain lists inputs; range lists outputs.
5-> Square brackets include an endpoint; parentheses do not.
6-> A function assigns each input exactly one output.
7-> A vertical line meets a function graph at most once.
8-> Compare shape, intercepts, domain, and range.
9o Constant Parent
10-> f(x) = a gives the same output for every input.
11-> Its graph is the horizontal line y = a.
12-> Domain: R. Range: {a}, a single value.
13-> For x = -2, -1, 0, 1, 2, outputs are a, a, a, a, a.
14-> Example: f(x) = 3 has range {3}.
15-> Its y-intercept is (0,a); if a != 0, it has no zero.
16-> If a = 0, every real input is a zero.
17o Identity Parent
18-> f(x) = x returns the input unchanged.
19-> Its graph is a line through (0,0) with slope 1.
20-> Domain: R. Range: R.
21-> Table inputs: x = -2, -1, 0, 1, 2.
22-> Table outputs: y = -2, -1, 0, 1, 2.
23-> Example: f(-2) = -2 and f(2) = 2.
24-> Both intercepts are (0,0); the function increases.

1.7.1 Parent Functions

Page 2 · Lines 25–48

25o Absolute Value Parent
26-> f(x) = |x| measures distance from zero.
27-> Domain: R. Range: [0,inf).
28-> Table inputs: x = -2, -1, 0, 1, 2.
29-> Table outputs: y = 2, 1, 0, 1, 2.
30-> The V has vertex (0,0) and y-axis symmetry.
31-> For x < 0, |x| = -x; for x >= 0, |x| = x.
32-> The minimum is 0; opposite inputs give equal outputs.
33o Quadratic Parent
34-> f(x) = x^2 squares each input.
35-> Domain: R. Range: [0,inf).
36-> Table inputs: x = -2, -1, 0, 1, 2.
37-> Table outputs: y = 4, 1, 0, 1, 4.
38-> The parabola opens up with vertex (0,0).
39-> It has y-axis symmetry and a minimum of 0.
40-> Unlike |x|, it curves; both have nonnegative outputs.
41o Choosing Models
42-> Constant: temperature held fixed over a time interval.
43-> Linear: wages W(t) = r*t at a fixed hourly rate r.
44-> Identity is the linear parent; wages need scaling.
45-> Quadratic: hypothetical projectile height H(t).
46-> H(t) = -t^2 + 4*t; 0 <= t <= 4; range: [0,4].
47-> Absolute value: |s-c| is distance from reference c.
48-> s is signed position, not total distance traveled.

1.7.2 Translations of Functions

Page 1 · Lines 1–24

1o Translation Rule
2-> A translation moves a graph without changing its shape.
3-> Write g(x) = f(x-h) + k for parent function f.
4-> h is the horizontal shift; k is the vertical shift.
5-> h > 0 moves right; h < 0 moves left.
6-> k > 0 moves up; k < 0 moves down.
7-> Inside signs look opposite; outside signs act the same.
8-> A parent point (u,v) becomes (u+h,v+k).
9o Reading Shifts
10-> g(x) = (x+2)^2 - 4 uses parent f(x) = x^2.
11-> x+2 = x-(-2), so h = -2 and k = -4.
12-> Shift left 2 and down 4; vertex: (-2,-4).
13-> Parent (1,1) becomes (-1,-3).
14-> g(x) = |x-7| + 1 shifts right 7 and up 1.
15-> Its vertex is (7,1); (1,1) becomes (8,2).
16-> Check: g(8) = |8-7| + 1 = 2.
17o Writing Equations
18-> Begin with the parent, then insert the requested shifts.
19-> Quadratic right 10 and up 4: h = 10, k = 4.
20-> The equation is g(x) = (x-10)^2 + 4.
21-> The vertex moves from (0,0) to (10,4).
22-> Parent (2,4) moves to (12,8).
23-> Check: g(12) = (12-10)^2 + 4 = 8.
24-> Shifts preserve the parabola's width and opening.

1.7.2 Translations of Functions

Page 2 · Lines 25–48

25o Quadratic Worked Points
26-> For g(x) = (x+5)^2 - 3, h = -5 and k = -3.
27-> Translate the parent left 5 and down 3.
28-> (0,0) becomes vertex (-5,-3).
29-> (1,1) becomes (-4,-2).
30-> (2,4) becomes (-3,1).
31-> Check: g(-3) = 2^2 - 3 = 1.
32-> Domain: R. Range: [-3,inf); axis: x = -5.
33o Absolute Value Worked Points
34-> For g(x) = |x+8| - 5, h = -8 and k = -5.
35-> Translate left 8 and down 5; vertex: (-8,-5).
36-> Parent (-1,1) becomes (-9,-4).
37-> Parent (1,1) becomes (-7,-4).
38-> Domain: R. Range: [-5,inf).
39-> The axis of symmetry is x = -8.
40-> Check: g(-7) = |-7+8| - 5 = -4.
41o Factoring and Checks
42-> Read h from a fully factored inside expression.
43-> With a scale, use b(x-h), not the raw constant.
44-> Example: 2x-6 = 2(x-3), so h = 3, not 6.
45-> This combines horizontal scaling with a shift.
46-> For pure translations, the inside coefficient is 1.
47-> Shift domain horizontally and range vertically.
48-> Verify a vertex and a second point by substitution.

1.7.3 Dilations and Reflections

Page 1 · Lines 1–24

1o Vertical Dilations
2-> In g(x) = a*f(x), multiply each output by a.
3-> Use a != 0 for the dilation rules here.
4-> |a| > 1 stretches vertically by |a|.
5-> 0 < |a| < 1 compresses vertically by |a|.
6-> a < 0 also reflects across the x-axis.
7-> A parent point (u,v) becomes (u,a*v).
8-> x stays fixed; a negative a reverses output signs.
9o Horizontal Dilations
10-> In g(x) = f(b*x), use b != 0.
11-> The horizontal factor is 1/|b|, not |b|.
12-> |b| > 1 compresses horizontally by 1/|b|.
13-> 0 < |b| < 1 stretches horizontally by 1/|b|.
14-> b < 0 also reflects across the y-axis.
15-> A parent point (u,v) becomes (u/b,v).
16-> Solve b*x = u to locate the new input x = u/b.
17o Linear Worked Examples
18-> Use identity f(x) = x as the parent.
19-> g(x) = -(2/5)*x has a = -2/5.
20-> Compress vertically by 2/5 and reflect across x-axis.
21-> (5,5) becomes (5,-2); check: -(2/5)*5 = -2.
22-> g(x) = -3*x has a = -3.
23-> Stretch vertically by 3 and reflect across x-axis.
24-> (1,1) becomes (1,-3); both graphs pass through (0,0).

1.7.3 Dilations and Reflections

Page 2 · Lines 25–48

25o Even Parent Examples
26-> g(x) = (-2.5*x)^2 uses f(x) = x^2, b = -2.5.
27-> Compress horizontally by 2/5 and reflect across y-axis.
28-> Since x^2 is even, that reflection is invisible.
29-> (2,4) becomes (-0.8,4); g(x) = 6.25*x^2.
30-> g(x) = (2/3)*|-x| reflects across y-axis.
31-> It also compresses vertically by 2/3.
32-> Since |-x| = |x|, this reflection is also invisible.
33o Combining Two Dilations
34-> In g(x) = a*f(b*x), use nonzero a and b.
35-> Map (u,v) to (u/b,a*v); divide input, scale output.
36-> Reflect x, compress horizontally 1/2, stretch vertically 8.
37-> For x^2, choose a = -8 and b = 2.
38-> g(x) = -8*(2*x)^2 = -32*x^2.
39-> For g(x) = -4*|2*x|, (-2,2) becomes (-1,-8).
40-> The other parent point (2,2) becomes (1,-8).
41o Equivalent Descriptions
42-> g(x) = (-3*x)^2 = 9*x^2.
43-> Inside form: compress horizontally 1/3; reflect y-axis.
44-> Outside form: stretch vertically by 9, with no reflection.
45-> Both descriptions produce the same graph.
46-> Even parents satisfy f(-x) = f(x).
47-> Their y-axis reflections can be invisible.
48-> Parameter representations need not be unique.

1.7.3 Combined Transformations

Page 1 · Lines 1–24

1o Combined Rule
2-> Use g(x) = a*f(b*(x-h)) + k with a,b != 0.
3-> Map parent (u,v) to (u/b+h,a*v+k).
4-> Divide by b; do not multiply the input by b.
5-> Dilation and reflection come before the shifts.
6-> a controls vertical scale and x-axis reflection.
7-> b controls reciprocal horizontal scale and y-reflection.
8-> h shifts horizontally; k shifts vertically.
9o Factor Before Reading
10-> Factor the entire inside to find b and h.
11-> 0.4*x+2 = 0.4*(x+5), so b = 0.4, h = -5.
12-> The shift is left 5, not left 2.
13-> g(x) = -(0.4*x+2) uses identity f(x) = x.
14-> Here a = -1, b = 0.4, h = -5, k = 0.
15-> Stretch horizontally by 2.5; reflect x; shift left 5.
16-> Equivalent: g(x) = -0.4*x-2; (0,0) maps to (-5,0).
17o Absolute Value Combined
18-> g(x) = -(2/3)*|x+3| + 1 uses a = -2/3, b = 1.
19-> Reflect x; compress vertically 2/3; left 3; up 1.
20-> h = -3, k = 1, so the vertex is (-3,1).
21-> (3,3) maps to (0,-1); check: g(0) = -2+1 = -1.
22-> The V opens down; its maximum output is 1.
23-> Domain: R. Range: (-inf,1].
24-> With b = 1 only, the mapping is (u+h,a*v+k).

1.7.3 Combined Transformations

Page 2 · Lines 25–48

25o Quadratic Combined
26-> Start with f(x) = x^2.
27-> Open down, stretch vertically 4, right 2, down 5.
28-> Choose a = -4, b = 1, h = 2, k = -5.
29-> The equation is g(x) = -4*(x-2)^2 - 5.
30-> Vertex: (2,-5); axis: x = 2; maximum: -5.
31-> (1,1) maps to (3,-9); check: g(3) = -4-5 = -9.
32-> Domain: R. Range: (-inf,-5]; there are no real zeros.
33o Dolphin Model
34-> g(x) = -0.125*(x-12)^2 + 18 models height.
35-> Vertex: (12,18); maximum height: 18 distance units.
36-> Zero height: 0 = -0.125*(x-12)^2 + 18.
37-> Thus (x-12)^2 = 144; x-12 = +/-12.
38-> Zeros: x = 0 and x = 24; symmetry axis: x = 12.
39-> Context domain: [0,24]; context range: [0,18].
40-> The packet does not specify distance units.
41o Reflection and Point Check
42-> g(x) = -2*|-(x-5)| + 4 has a = -2, b = -1.
43-> Reflect y then x; stretch vertically 2; right 5; up 4.
44-> h = 5, k = 4; vertex: (5,4); range: (-inf,4].
45-> (0,0) maps to (5,4); domain: R.
46-> (-1,1) maps to (6,2); (1,1) maps to (4,2).
47-> Absolute value hides the y-axis reflection.
48-> Check each mapped point by substituting into g(x).
