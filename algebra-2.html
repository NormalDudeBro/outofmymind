2-> Solve for y before building a table.
3-> x + 3y - 6 = 0 gives 3y = -x + 6.
4-> Divide by 3: y = -x/3 + 2.

9-> Pick x values that make the division easy, like 0 and 6.
10-> Equal x steps of 3 give equal y steps of -1: slope -1/3.
11o Intercepts and Slope
12-> For 3x - 2y = -12, set y = 0 to find x.
13-> 3x = -12 gives the x-intercept (-4, 0).
14-> Set x = 0: -2y = -12 gives (0, 6).
15-> Draw the line through these two intercepts.
16-> In y = (3/2)x - 4, slope is 3/2.
17-> Start at (0, -4); move right 2 and up 3.
18-> Slope means change in y divided by change in x.
19-> The intercepts are (-4, 0) and (0, 6); no other crossings.
20-> Slope from the intercepts is (6 - 0)/(0 - (-4)) = 3/2.
21o Inequality Boundaries
22-> Replace the inequality sign with = for the boundary.
23-> Use a solid line for <= or >=; equality is included.
24-> Use a dashed line for < or >; equality is excluded.
25-> For y < mx + b, shade below the boundary.
26-> For y > mx + b, shade above the boundary.
27-> Multiplying or dividing by a negative reverses the sign.
28-> For x < c, the vertical boundary is x = c; shade left.
29-> For x > c, use a dashed vertical line and shade right.

1.6.1 Piecewise Functions

Page 1 · Lines 1–29

1o Choosing a Branch
2-> A piecewise function uses different rules on input intervals.
3-> Choose the branch by the input, not by the output.
4-> First compare x with each branch's interval condition.
5-> Substitute into only the rule whose condition holds.
6-> An included input must have exactly one output.
7-> Check boundary inputs carefully for < versus <=.
8-> An input outside all listed intervals is outside the domain.
9-> A branch condition may test x, or it may name an interval.
10-> With x >= 2 listed, every larger x is already covered.
11o Worked Piecewise Example
12-> Illustrative example using three distinct input intervals.
13-> Define f(x) = 2x for x < 0.
14-> Define f(x) = 3 for 0 <= x < 2.
15-> Define f(x) = -x + 5 for x >= 2.
16-> f(-2) = 2(-2) = -4 using the first branch.
17-> f(1) = 3 using the middle branch.
18-> f(4) = -4 + 5 = 1 using the last branch.
19-> f(0) uses the middle branch because 0 satisfies 0 <= 0.
20-> f(2) uses the last branch because 2 satisfies x >= 2.
21o Restricted Graphs
22-> Graph each rule only on its assigned input interval.
23-> For the example, draw y = 2x only to the left of x = 0.
24-> Mark (0, 0) open; mark (0, 3) closed.
25-> Draw y = 3 from x = 0 up to, but not including, x = 2.
26-> The middle branch has an open endpoint at (2, 3).
27-> The last branch includes (2, 3); the final point is closed.
28-> Thus f(0) = 3 and f(2) = 3, each with one output.
29-> f is increasing, flat, then decreasing across its domain.

1.6.2 Step Functions

Page 1 · Lines 1–29

1o Step Function Basics
2-> A step function is constant on each input interval.
3-> Its graph consists of horizontal segments or rays.
4-> Output changes at boundaries between steps.
5-> Outputs form a discrete set in the usual step models.
6-> Inputs may vary continuously across real intervals.
7-> A context may instead allow only discrete inputs.
8-> State the domain from the model, not just the picture.
9-> Inside one step, rise over run is 0, so the slope is 0.
10-> Jumps happen only at interval endpoints, never inside.
11o Greatest Integer Rule
12-> floor(x) is the greatest integer less than or equal to x.
13-> It rounds down toward negative infinity.
14-> floor(10.7) = 10 because 10 <= 10.7 < 11.
15-> floor(-6.35) = -7 because -7 <= -6.35 < -6.
16-> floor(5) = 5; an integer stays unchanged.
17-> floor(-0.2) = -1, not 0.
18-> Truncation toward zero is not floor for negative nonintegers.
19-> floor(2.999) = 2; the value never reaches the next integer.
20-> Writing x = 5 + r with 0 <= r < 1 gives floor(x) = 5.
21o Floor Intervals
22-> For an integer k, floor(x) = k when k <= x < k + 1.
23-> The left endpoint is closed; the right endpoint is open.
24-> y = 0 on 0 <= x < 1; y = 1 on 1 <= x < 2.
25-> y = -2 on -2 <= x < -1.
26-> At x = -1, use the next step: floor(-1) = -1.
27-> The domain of floor(x) is all real numbers.
28-> The range of floor(x) is all integers.
29-> floor(x) = -1 on -1 <= x < 0, not -1 < x < 0.

30o Transformed Floor Rule
31-> Let f(x) = floor(2x - 1); let k be an integer.
32-> f(x) = k exactly when k <= 2x - 1 < k + 1.
33-> Add 1: k + 1 <= 2x < k + 2.
34-> Divide by 2: (k + 1)/2 <= x < (k + 2)/2.
35-> Each step has width 1/2, closed left and open right.
36-> The domain is all real numbers; the range is all integers.
37-> A positive input coefficient preserves endpoint order.
38-> A coefficient a > 0 makes each step width 1/a.
39-> With 2x - 1 inside, steps break where 2x - 1 is an integer.
40o Transformed Examples
41-> For k = 0, f(x) = 0 on 1/2 <= x < 1.
42-> f(0.75) = floor(0.5) = 0.
43-> At x = 1, f(1) = floor(1) = 1, not 0.
44-> For k = -1, f(x) = -1 on 0 <= x < 1/2.
45-> f(0.25) = floor(-0.5) = -1.
46-> For k = -2, f(x) = -2 on -1/2 <= x < 0.
47-> f(-0.25) = floor(-1.5) = -2.
48-> For k = 1, f(x) = 1 on the next step to the right.
49-> f(0.6) = floor(0.2) = 0, so the input lies in 1/2 to 1.
50o Context and Endpoints
51-> Parking fees can stay constant within each time bracket.
52-> Read each interval and its included endpoints from the source.
53-> Open circles exclude points; closed circles include them.
54-> Two included outputs at one input violate the function rule.
55-> Included branches with the same output still give one value.
56-> Two open endpoints at an input may leave it out of the domain.
57-> Check boundary values before using a step model for a charge.
58-> Two brackets meeting at one time must agree or the rule fails.

1.6.3 Absolute Value Functions

Page 1 · Lines 1–29

1o Absolute Value Rule
2-> Absolute value measures distance from zero, never negative.
3-> |x| = x if x >= 0.
4-> |x| = -x if x < 0.
5-> For example, |-5| = -(-5) = 5 and |5| = 5.
6-> The parent graph is a V with vertex (0, 0).
7-> Its domain is all real numbers; its range is y >= 0.
8-> Opposite inputs have equal absolute values.
9-> |x - c| is the distance between the input and the point c.
10-> Factoring: |2x - 6| = 2|x - 3| leaves the zeros unchanged.
11o General Graph Form
12-> Write y = a|x - h| + k, with a != 0.
13-> The vertex is (h, k); the symmetry line is x = h.
14-> The domain is all real numbers.
15-> If a > 0, the V opens upward and the range is y >= k.
16-> If a < 0, the V opens downward and the range is y <= k.
17-> The left branch slope is -a; the right branch slope is a.
18-> Larger |a| makes a steeper V; smaller |a| makes it flatter.
19-> The V meets the x-axis exactly when a*k <= 0.
20-> Points the same distance from h give the same output y.
21o Upward Worked Example
22-> For y = |x - 1| + 3, a = 1, h = 1, and k = 3.
23-> The vertex is (1, 3); the symmetry line is x = 1.
24-> The minimum output is 3; the range is y >= 3.
25-> At x = 0 or x = 2, y = 4.
26-> At x = -1 or x = 3, y = 5.
27-> For x < 1, y = -(x - 1) + 3 = -x + 4.
28-> For x >= 1, y = x - 1 + 3 = x + 2.
29-> x-intercepts: |x - 1| = -3 has none, so no crossings.

1.6.3 Absolute Value Functions

Page 2 · Lines 30–58

30o Downward Worked Example
31-> For y = -(2/3)|x + 3| + 1, h = -3, not 3.
32-> The vertex is (-3, 1); the symmetry line is x = -3.
33-> Since a = -2/3, the maximum output is 1.
34-> The domain is all real numbers; the range is y <= 1.
35-> The left slope is 2/3; the right slope is -2/3.
36-> At x = -6 or x = 0, y = -(2/3)(3) + 1 = -1.
37-> Plot these symmetric points and draw the two rays.
38-> At x = -3 the absolute term vanishes, leaving y = 1.
39-> The y-intercept is (0, -1), one of the symmetric points.
40o Equation Strategy
41-> Isolate the absolute value before splitting into cases.
42-> For |u| = q with q < 0, there are no real solutions.
43-> For q = 0, solve u = 0; for nonconstant linear u, one root.
44-> For q > 0, solve u = q or u = -q.
45-> If u is linear with nonzero slope, q > 0 gives two roots.
46-> For nonlinear u, the number of roots can differ.
47-> Check roots in the original equation for extraneous roots.
48-> Graph view: |u| = q cuts the curve y = |u| at height q.
49-> After splitting, keep each branch with its case condition.
50o Solve and Check
51-> Solve 2|x - 1| + 3 = 11: first get |x - 1| = 4.
52-> x - 1 = 4 or x - 1 = -4 gives x = 5 or x = -3.
53-> Check both: 2(4) + 3 = 11, so both are solutions.
54-> |x + 2| = -3 has no solutions: distance cannot be negative.
55-> |x + 2| = 0 gives x = -2, exactly one solution.
56-> Squaring |x + 2| = -3 would falsely suggest x = 1 or -5.
57-> Both fail the original equation; reject those extra roots.
58-> |x - 2| = 5 gives x = 7 and x = -3, both checked.

1.7.1 Parent Functions

Page 1 · Lines 1–29

1o Parent Functions
2-> A parent is a basic function used to build a family.
3-> R means all real numbers; inf means infinity.
4-> Domain lists inputs; range lists outputs.
5-> Square brackets include an endpoint; parentheses do not.
6-> A function assigns each input exactly one output.
7-> A vertical line meets a function graph at most once.
8-> Compare shape, intercepts, domain, and range.
9-> The x-intercept is where y = 0; the y-intercept is x = 0.
10-> Rates of change separate constant, linear, and curved parents.
11o Constant Parent
12-> f(x) = a gives the same output for every input.
13-> Its graph is the horizontal line y = a.
14-> Domain: R. Range: {a}, a single value.
15-> For x = -2, -1, 0, 1, 2, outputs are a, a, a, a, a.
16-> Example: f(x) = 3 has range {3}.
17-> Its y-intercept is (0,a); if a != 0, it has no zero.
18-> If a = 0, every real input is a zero.
19-> Slope is 0, so every secant line is horizontal.
20-> Average rate of change is 0 between any two distinct inputs.
21o Identity Parent
22-> f(x) = x returns the input unchanged.
23-> Its graph is a line through (0,0) with slope 1.
24-> Domain: R. Range: R.
25-> Table inputs: x = -2, -1, 0, 1, 2.
26-> Table outputs: y = -2, -1, 0, 1, 2.
27-> Example: f(-2) = -2 and f(2) = 2.
28-> Both intercepts are (0,0); the function increases.
29-> Average rate of change is 1 on every interval.

Page 2 · Lines 30–58

30o Absolute Value Parent
31-> f(x) = |x| measures distance from zero.
32-> Domain: R. Range: [0,inf).
33-> Table inputs: x = -2, -1, 0, 1, 2.
34-> Table outputs: y = 2, 1, 0, 1, 2.
35-> The V has vertex (0,0) and y-axis symmetry.
36-> For x < 0, |x| = -x; for x >= 0, |x| = x.
37-> The minimum is 0; opposite inputs give equal outputs.
38-> Rate of change: -1 on (-inf,0) and 1 on (0,inf).
39-> It is not linear: slopes jump from -1 to 1 at x = 0.
40o Quadratic Parent
41-> f(x) = x^2 squares each input.
42-> Domain: R. Range: [0,inf).
43-> Table inputs: x = -2, -1, 0, 1, 2.
44-> Table outputs: y = 4, 1, 0, 1, 4.
45-> The parabola opens up with vertex (0,0).
46-> It has y-axis symmetry and a minimum of 0.
47-> Unlike |x|, it curves; both have nonnegative outputs.
48-> From 0 to h != 0, average rate of change is h^2/h = h.
49-> Equal input steps give unequal changes in squared outputs.
50o Choosing Models
51-> Constant: temperature held fixed over a time interval.
52-> Linear: wages W(t) = r*t at a fixed hourly rate r.
53-> Identity is the linear parent; wages need scaling.
54-> Quadratic: hypothetical projectile height H(t).
55-> H(t) = -t^2 + 4*t; 0 <= t <= 4; range: [0,4].
56-> Absolute value: |s-c| is distance from reference c.
57-> s is signed position, not total distance traveled.
58-> Wages at $12 per hour: W(30) = 12*30 = 360 dollars.

1.7.2 Translations of Functions

Page 1 · Lines 1–29

1o Translation Rule
2-> A translation moves a graph without changing its shape.
3-> Write g(x) = f(x-h) + k for parent function f.
4-> h is the horizontal shift; k is the vertical shift.
5-> h > 0 moves right; h < 0 moves left.
6-> k > 0 moves up; k < 0 moves down.
7-> Inside signs look opposite; outside signs act the same.
8-> A parent point (u,v) becomes (u+h,v+k).
9-> Translations preserve the size of the domain and range.
10-> Every point shifts the same way; the graph never flips.
11o Reading Shifts
12-> g(x) = (x+2)^2 - 4 uses parent f(x) = x^2.
13-> x+2 = x-(-2), so h = -2 and k = -4.
14-> Shift left 2 and down 4; vertex: (-2,-4).
15-> Parent (1,1) becomes (-1,-3).
16-> g(x) = |x-7| + 1 shifts right 7 and up 1.
17-> Its vertex is (7,1); (1,1) becomes (8,2).
18-> Check: g(8) = |8-7| + 1 = 2.
19-> For g(x) = |x-7| + 1, the range is [1,inf).
20-> The parent range [0,inf) shifts to [-4,inf).
21o Writing Equations
22-> Begin with the parent, then insert the requested shifts.
23-> Quadratic right 10 and up 4: h = 10, k = 4.
24-> The equation is g(x) = (x-10)^2 + 4.
25-> The vertex moves from (0,0) to (10,4).
26-> Parent (2,4) moves to (12,8).
27-> Check: g(12) = (12-10)^2 + 4 = 8.
28-> Shifts preserve the parabola's width and opening.
29-> Left 10 and up 4 gives h = -10 and k = 4.

58-> Factored check: x^2 - 6x + 9 = (x-3)^2, so h = 3, k = 0.

1.7.3 Dilations and Reflections

Page 1 · Lines 1–29

1o Vertical Dilations
2-> In g(x) = a*f(x), multiply each output by a.
3-> Use a != 0 for the dilation rules here.
4-> |a| > 1 stretches vertically by |a|.
5-> 0 < |a| < 1 compresses vertically by |a|.
6-> a < 0 also reflects across the x-axis.
7-> A parent point (u,v) becomes (u,a*v).
8-> x stays fixed; a negative a reverses output signs.
9-> Zeros persist: f(c) = 0 gives g(c) = a*f(c) = 0.
10-> The y-intercept is not fixed: it becomes a*f(0) at x = 0.
11o Horizontal Dilations
12-> In g(x) = f(b*x), use b != 0.
13-> The horizontal factor is 1/|b|, not |b|.
14-> |b| > 1 compresses horizontally by 1/|b|.
15-> 0 < |b| < 1 stretches horizontally by 1/|b|.
16-> b < 0 also reflects across the y-axis.
17-> A parent point (u,v) becomes (u/b,v).
18-> Solve b*x = u to locate the new input x = u/b.
19-> Outputs never move; only the input coordinate is rescaled.
20-> With b = 1/2, stretch by 2; with b = 2, compress by 1/2.
21o Linear Worked Examples
22-> Use identity f(x) = x as the parent.
23-> g(x) = -(2/5)*x has a = -2/5.
24-> Compress vertically by 2/5 and reflect across x-axis.
25-> (5,5) becomes (5,-2); check: -(2/5)*5 = -2.
26-> g(x) = -3*x has a = -3.
27-> Stretch vertically by 3 and reflect across x-axis.
28-> (1,1) becomes (1,-3); both graphs pass through (0,0).
29-> The slope of the image line equals a times the parent slope.

1.7.3 Dilations and Reflections

Page 2 · Lines 30–58

30o Even Parent Examples
31-> g(x) = (-2.5*x)^2 uses f(x) = x^2, b = -2.5.
32-> Compress horizontally by 2/5 and reflect across y-axis.
33-> Since x^2 is even, that reflection is invisible.
34-> (2,4) becomes (-0.8,4); g(x) = 6.25*x^2.
35-> g(x) = (2/3)*|-x| reflects across y-axis.
36-> It also compresses vertically by 2/3.
37-> Since |-x| = |x|, this reflection is also invisible.
38-> The same trick works for |x| and every other even parent.
39-> Even symmetry gives f(-b*x) = f(b*x), not f(b*x) = f(x).
40o Combining Two Dilations
41-> In g(x) = a*f(b*x), use nonzero a and b.
42-> Map (u,v) to (u/b,a*v); divide input, scale output.
43-> Reflect x, compress horizontally 1/2, stretch vertically 8.
44-> For x^2, choose a = -8 and b = 2.
45-> g(x) = -8*(2*x)^2 = -32*x^2.
46-> For g(x) = -4*|2*x|, (-2,2) becomes (-1,-8).
47-> The other parent point (2,2) becomes (1,-8).
48-> For a power parent, the coefficient becomes a*b^k.
49-> The sign of b is free for even parents: -2 works like 2.
50o Equivalent Descriptions
51-> g(x) = (-3*x)^2 = 9*x^2.
52-> Inside form: compress horizontally 1/3; reflect y-axis.
53-> Outside form: stretch vertically by 9, with no reflection.
54-> Both descriptions produce the same graph.
55-> Even parents satisfy f(-x) = f(x).
56-> Their y-axis reflections can be invisible.
57-> Parameter representations need not be unique.

1o Standard Form
2-> Standard form is Ax + By = C with A, B not both zero.
3-> Convention: A >= 0; A, B, C integers; gcd 1.
4-> gcd is greatest common factor; clear fractions when rational.
5-> Example: y = (2/5)x + 14 becomes 2x - 5y = -70.
6-> Subtract (2/5)x: -(2/5)x + y = 14.
7-> Multiply by -5: 2x - 5y = -70.
8-> Here A = 2, B = -5, and C = -70.
9-> Check: -2x + 2y = 2 is not standard; divide by 2.
10-> It reduces to -x + y = 1; multiply by -1: x - y = -1.
11o Slope Intercept
12-> Slope-intercept form is y = mx + b.
13-> m is the slope; b is the y-intercept, not standard B.
14-> Solve the equation for y before reading either value.
15-> Example: 12x - 4y = 24.
16-> Subtract 12x: -4y = -12x + 24.
17-> Divide by -4: y = 3x - 6, so m = 3 and b = -6.
18-> Check 4x = -2y + 22.
19-> Add 2y: 4x + 2y = 22, then 2y = -4x + 22.
20-> Thus y = -2x + 11; a positive 2 is wrong.
21o Point Slope
22-> Point-slope form is y - y1 = m(x - x1).
23-> m is the slope and (x1, y1) is one point on the line.
24-> Example: slope 7 through (2, -3).
25-> Substitute: y - (-3) = 7(x - 2).
26-> Simplify the left side: y + 3 = 7(x - 2).
27-> Expand and solve for y to reach slope-intercept form.
28-> y + 3 = 7x - 14 gives y = 7x - 17.
29-> Check (2, -3): 7(2) - 17 = -3, as required.

9-> The lines meet at (2, 3).
10-> Check: 2(2) - 1 = 3 and -(2) + 5 = 3.
11o Classification
12-> One intersection means one solution.
13-> The system is consistent and independent.
14-> Identical lines mean infinitely many solutions.
15-> The system is consistent and dependent.
16-> Parallel distinct lines mean no solution.
17-> The system is inconsistent.
18-> Different slopes: one solution.
19-> Same slope and same intercept: infinitely many.
20-> Same slope and different intercepts: none.
21o One Solution
22-> Example: 3x + y = 10 and x - y = 2.
23-> Solve each for y: y = -3x + 10 and y = x - 2.
