(pen)o (pu)Greatest Integer Rule(pen)
(pen)-> floor(x) is the (pu)greatest integer(pen) less than or equal to x.
(pen)-> It rounds down toward negative infinity.
(pen)-> floor(10.7) = 10 because 10 <= 10.7 < 11.
(pen)-> floor(-6.35) = -7 because -7 <= -6.35 < -6.
(pen)-> floor(5) = 5; an integer stays unchanged.
(pen)-> floor(-0.2) = -1, not 0.
(pen)-> (pu)Truncation(pen) toward zero is not floor for negative nonintegers.
(pen)o (br)Floor Intervals(pen)
(pen)-> For an integer k, floor(x) = k when k <= x < k + 1.
(pen)-> The left endpoint is (br)closed(pen); the right endpoint is open.
(pen)-> y = 0 on 0 <= x < 1; y = 1 on 1 <= x < 2.
(pen)-> y = -2 on -2 <= x < -1.
(pen)-> At x = -1, use the next step: floor(-1) = -1.
(pen)-> The (br)domain(pen) of floor(x) is all real numbers.
(pen)-> The range of floor(x) is all integers.
(pen)o (db)Transformed Floor Rule(pen)
(pen)-> Let f(x) = floor(2x - 1); let k be an integer.
(pen)-> f(x) = k exactly when k <= 2x - 1 < k + 1.
(pen)-> Add 1: k + 1 <= 2x < k + 2.
(pen)-> Divide by 2: (k + 1)/2 <= x < (k + 2)/2.
(pen)-> Each step has (db)width(pen) 1/2, closed left and open right.
(pen)-> The domain is all real numbers; the range is all integers.
(pen)-> A positive input coefficient preserves (db)endpoint order(pen).
