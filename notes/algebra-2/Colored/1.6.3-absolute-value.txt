(pen)o (g)Absolute Value Rule(pen)
(pen)-> Absolute value measures (g)distance(pen) from zero, never negative.
(pen)-> |x| = x if x >= 0.
(pen)-> |x| = -x if x < 0.
(pen)-> For example, |-5| = -(-5) = 5 and |5| = 5.
(pen)-> The parent graph is a V with (g)vertex(pen) (0, 0).
(pen)-> Its domain is all real numbers; its range is y >= 0.
(pen)-> Opposite inputs have equal absolute values.
(pen)-> |x - c| is the distance between the input and the point c.
(pen)-> (g)Factoring(pen): |2x - 6| = 2|x - 3| leaves the zeros unchanged.
(pen)o (pu)General Graph Form(pen)
(pen)-> Write y = a|x - h| + k, with a != 0.
(pen)-> The vertex is (h, k); the (pu)symmetry line(pen) is x = h.
(pen)-> The domain is all real numbers.
(pen)-> If a > 0, the V opens upward and the range is y >= k.
(pen)-> If a < 0, the V opens downward and the range is y <= k.
(pen)-> The left branch slope is -a; the right branch slope is a.
(pen)-> Larger |a| makes a (pu)steeper(pen) V; smaller |a| makes it flatter.
(pen)-> The V meets the x-axis exactly when a*k <= 0.
(pen)-> Points the same distance from h give the same (pu)output(pen) y.

(pen)-> The (br)minimum(pen) output is 3; the range is y >= 3.

(pen)o (hp)Equation Strategy(pen)
(pen)-> (hp)Isolate(pen) the absolute value before splitting into cases.
(pen)-> For |u| = q with q < 0, there are no real solutions.
(pen)-> For q = 0, solve u = 0; for nonconstant linear u, one root.
(pen)-> For q > 0, solve u = q or u = -q.
(pen)-> If u is linear with nonzero slope, q > 0 gives two roots.
(pen)-> For nonlinear u, the number of roots can differ.
(pen)-> Check roots in the original equation for (hp)extraneous roots(pen).
(pen)-> Graph view: |u| = q cuts the curve y = |u| at height q.
(pen)-> After (hp)splitting(pen), keep each branch with its case condition.

(pen)-> x - 1 = 4 or x - 1 = -4 gives x = 5 or x = -3.
(pen)-> (hp)Check(pen) both: 2(4) + 3 = 11, so both are solutions.
(pen)-> |x + 2| = -3 has no solutions: distance cannot be negative.

(pen)-> |x - 2| = 5 gives x = 7 and x = -3, both checked.
